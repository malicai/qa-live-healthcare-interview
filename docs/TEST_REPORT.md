## 4. 缺陷与风险

未发现代码缺陷。测试过程中记录以下注意事项:

| 项目 | 说明 | 处理 |
| ---- | ---- | ---- |
| Windows 终端编码 | Git Bash 以 GBK 发送含中文的请求体时会导致 JSON 解析失败 | 脚本通过 UTF-8 文件 + `--data-binary` 发送请求体,规避该问题 |
| 畸形 JSON 响应 | 早期版本对非 JSON 请求体返回 500 | 已补充 `HttpMessageNotReadableException` 处理,现返回 400 `VALIDATION_ERROR`(本次 P10 验证通过) |
| 登录限流 | 当前未实现登录限流/失败锁定 | 建议后续迭代增加,已记录于 PRD 风险章节 |
